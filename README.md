## Quick tips

1. Use a clear, front-facing portrait with good lighting.
2. Keep the face recognizable throughout the transformation.
3. Ask for smooth motion, stable anatomy, and consistent clothing.
4. Use a vertical `9:16` composition for TikTok, Reels, and Shorts.
5. Only upload photos you own or have permission to use.
